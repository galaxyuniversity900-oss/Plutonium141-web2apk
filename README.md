# عُمران — إدارة العمارات والشقق

نسخة عربية RTL مستقلة من نظام إدارة العمارات والسكان والحسابات، مهيأة للتغليف كتطبيق Android باستخدام Capacitor.

## الملفات
- `index.html`: ملف التطبيق المستقل الذي يتم تضمينه داخل APK.
- `عماره6.html`: نسخة المصدر الأصلية المستقلة.
- `app.js` و`style.css`: ملفات النسخة السابقة محفوظة دون حذف.
- `.github/workflows/build-apk.yml`: بناء APK آليًا باستخدام GitHub Actions.

## بناء APK
1. افتح تبويب Actions في المستودع.
2. اختر **Build Omran Android APK**.
3. اضغط **Run workflow** وانتظر انتهاء البناء.
4. افتح نتيجة التشغيل ثم نزّل artifact باسم `omran-android-debug-apk`.
5. فك ضغط artifact وثبّت `app-debug.apk` على Android. هذا APK للتجربة والتثبيت اليدوي وليس إصدارًا موقّعًا للنشر على المتاجر.

## التخزين والنسخ الاحتياطي
يستخدم التطبيق IndexedDB (schema version 3) للتخزين المحلي؛ يضيف سجل الإقامة عند ترقية القاعدة دون مسح السجلات الموجودة. لا توجد مزامنة تلقائية بين الأجهزة. صدّر نسخة احتياطية بانتظام، واختبر الاستعادة، واحفظ الملفات التي تحتوي على أرقام قومية أو صور هويات في مكان آمن.

## ملاحظات
- يحتاج بناء APK إلى GitHub Actions واتصال الإنترنت لتنزيل أدوات Android وCapacitor.
- اختبار بناء APK لا يثبت وحده أن كل مسار استخدام يعمل على كل هاتف؛ يجب تجربة الإضافة والتعديل والحذف والنسخ الاحتياطي والاستعادة على الجهاز المستهدف.
- البيانات المحلية قد تُفقد عند مسح بيانات التطبيق أو إلغاء تثبيته.
