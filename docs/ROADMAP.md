# عُمران — خارطة تطوير المنتج

## المطبق في المرحلة الحالية
- استوديو صور منفصل لكل شقة.
- رفع عدة صور في عملية واحدة، مع وصف واسم ساكن ووسوم.
- بحث في الوصف والاسم والوسوم، عرض مكبر، تنزيل الصورة، تعديل بياناتها وحذفها.
- ضغط الصور الكبيرة عند دعم المتصفح، مع تنبيه عند امتلاء التخزين.
- ترقية IndexedDB إلى الإصدار 4 دون مسح البيانات القديمة.
- حماية صور الشقة من الحذف غير المقصود عند حذف سجل الشقة.
- دعم النسخ الاحتياطي والاستعادة، مع الاحتفاظ بمخازن التطبيق الأحدث عند استيراد نسخة قديمة.

## مراحل مقترحة لتصبح النسخة متعددة المستخدمين وجاهزة للاستخدام المؤسسي
1. **الأمان والصلاحيات:** حسابات منفصلة، أدوار (مالك، مدير، محاسب، صيانة)، سجل تدقيق غير قابل للتعديل، تشفير فعلي للبيانات الحساسة.
2. **مزامنة سحابية اختيارية:** مزامنة مشفرة بين الهاتف والكمبيوتر، حل تعارضات التعديل، نسخ احتياطي مجدول واستعادة مختبرة. لا تُفعّل المزامنة دون خادم موثوق ومصادقة.
3. **الملفات والمستندات:** مستندات العقود والإيصالات ومحاضر الاستلام مرتبطة بالشقة والساكن، مع صلاحيات تنزيل وتواريخ انتهاء.
4. **المالية الاحترافية:** دفتر أستاذ مزدوج القيد، كشف حساب لكل شقة، متأخرات الإيجار، إيصالات PDF، إقفال الفترات، ومراجعة تسوية الصندوق.
5. **الصيانة الذكية:** طلبات خدمة مصورة، أولويات وSLA، تعيين فني، عروض أسعار، تكلفة قطع الغيار، وتاريخ إصلاحات لكل أصل.
6. **بوابة السكان:** طلبات الصيانة، الإبلاغ عن الأعطال، إيصالات الإيجار، الإشعارات، وتحديث بيانات التواصل بموافقة الإدارة.
7. **التقارير والتصدير:** تقارير شهرية قابلة للطباعة، Excel/CSV، مؤشرات الإشغال، متوسط زمن الإصلاح، التدفقات النقدية، وتكلفة كل مبنى.
8. **اللغات والعملات:** العربية RTL والإنجليزية LTR، عملة وإعدادات ضريبية حسب الدولة، تنسيقات التاريخ والأرقام المحلية.
9. **الامتثال والخصوصية:** سياسة احتفاظ بالصور، موافقات واضحة، إخفاء بيانات الهوية في التقارير، وتصدير/حذف البيانات وفق القوانين المحلية.
10. **جودة المنتج:** اختبارات واجهة آلية على الهاتف والكمبيوتر، ترحيلات قواعد بيانات قابلة للتراجع، مراقبة الأخطاء، وإمكانية الوصول.

## القيود الحالية
- التخزين محلي داخل المتصفح/التطبيق؛ لا توجد مزامنة تلقائية بين الأجهزة.
- لا يوجد حد عددي للصور في التطبيق، لكن مساحة الجهاز والمتصفح محدودة. الملفات الفردية التي تتجاوز 25 MiB تُرفض، والصور الكبيرة قد تُضغط.
- الصور المضافة إلى نسخة JSON تجعلها أكبر بكثير؛ جرّب الاستعادة على نسخة اختبار قبل الاعتماد عليها.
- لا تُعتبر هذه المرحلة نظامًا متعدد المستخدمين أو نظامًا محاسبيًا معتمدًا قبل تنفيذ الأمان والمزامنة والاختبارات المطلوبة.
