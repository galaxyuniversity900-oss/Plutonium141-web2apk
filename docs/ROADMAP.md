# ROWAD - عماره | خارطة التطوير والقرارات التصميمية

## المطبق في هذه النسخة
- استوديو صور مستقل لكل شقة: رفع متعدد، اسم ساكن ووصف ووسوم، بحث وعرض وتنزيل وتعديل وحذف.
- ترقية IndexedDB إلى الإصدار 4 دون مسح السجلات السابقة، مع حماية الصور من الحذف غير المقصود ودعم النسخ الاحتياطي والاستعادة المتوافقة.
- إعادة هوية التطبيق إلى **ROWAD - عماره**، مع لوحة ألوان بشرية هادئة: ورقي دافئ، زيتوني، رملي ولمسة طينية؛ بلا تدرجات نيون أو ألوان AI الشائعة.
- تحسين سهولة الاستخدام: تباين واضح، حالات تركيز مرئية للوحة المفاتيح، أهداف لمس مناسبة، تخطيط متجاوب، ودعم تقليل الحركة.
- قسم أذونات Android داخل الإعدادات يفتح صفحة معلومات التطبيق عبر جسر Capacitor أصلي في APK، ليختار المستخدم السماح/المنع من النظام.
- سياسة أذونات بأقل امتياز: لا تُطلب أذونات جهات الاتصال أو الموقع أو الميكروفون أو الرسائل أو سجل المكالمات لأنها غير لازمة للوظائف الحالية. اختيار الصور والملفات عبر منتقي Android لا يستدعي عادةً صلاحية تخزين شاملة.
- بناء APK Debug آليًا عبر GitHub Actions والتحقق من ملف الناتج ورفعه كـ artifact باسم ROWAD.

## خارطة الميزات المقترحة — موثقة حسب الأولوية

### أولوية P0 — سلامة البيانات والتشغيل
1. اختبار تثبيت وترقية التطبيق على أجهزة Android فعلية، والتحقق من بقاء البيانات بعد إعادة التشغيل وتحديث APK.
2. نسخ احتياطي تلقائي اختياري محلي مع تنبيه عند مرور مدة طويلة دون نسخة، واختبار استعادة آلي على قاعدة تجريبية.
3. تحسين إدارة مساحة الصور، عرض استهلاك التخزين، وفحص سلامة الملفات قبل الاستعادة.
4. معالجة أخطاء واضحة عند امتلاء التخزين أو رفض صلاحية يطلبها النظام مستقبلًا.

### أولوية P1 — العمل اليومي للعقار
5. ملف 360° لكل شقة يجمع بياناتها وسجل السكان والمغادرات والانتقالات والعقود والمالية والصيانة والصور في شاشة واحدة.
6. تنبيهات استحقاق الإيجار، التأخر، انتهاء العقود، صيانة دورية، تنظيف الخزانات، ومواعيد الغاز/المرافق.
7. توليد إيصالات وعقود ومحاضر استلام وتسليم PDF مع ترقيم وتاريخ وبيانات العقار.
8. سجل صور «قبل/بعد» لأعمال الصيانة والتلفيات، مع تكلفة وفني وتاريخ إنجاز.
9. بحث موحد في العمارات والشقق والسكان والملفات والمعاملات، مع فلاتر محفوظة.
10. تقارير شهرية قابلة للطباعة والتصدير: إشغال، متأخرات، صافي التدفقات، تكلفة الصيانة، حركة المخزون.

### أولوية P2 — المحاسبة والحوكمة
11. دفتر أستاذ مزدوج القيد، دليل حسابات، مراكز تكلفة لكل عمارة، كشف حساب ساكن، تسوية صندوق، وإقفال فترات.
12. أدوار وصلاحيات حقيقية (مالك، مدير، محاسب، صيانة، قراءة فقط) مع منع على مستوى البيانات لا مجرد إخفاء الأزرار.
13. سجل تدقيق يوضح من غيّر ماذا ومتى، مع حماية من العبث عند وجود خادم موثوق.
14. تشفير فعلي للبيانات الحساسة وإدارة مفاتيح آمنة؛ قفل الواجهة الحالي وحده لا يشفر قاعدة البيانات.

### أولوية P3 — تعدد الأجهزة والفرق
15. مزامنة مشفرة اختيارية بين Android وWindows، مع تسجيل دخول، حل تعارضات، وسياسة نسخ احتياطي واستعادة.
16. وضع دون اتصال أولًا، ومزامنة عند توفر الإنترنت دون فقد تعديلات متزامنة.
17. بوابة سكان اختيارية لطلبات الصيانة والإيصالات وتحديث التواصل، مع موافقة صريحة وتقليل البيانات المعروضة.
18. تعدد اللغات RTL/LTR والعملات والضرائب وتنسيقات التواريخ وفق الدولة.

### أولوية P4 — جودة المنتج وتجربة الاستخدام
19. اختبار آلي للواجهة على أحجام شاشات مختلفة، وفحوص إمكانية الوصول والتباين وقارئات الشاشة.
20. إعدادات كثافة العرض وحجم الخط، ورسائل أخطاء قابلة للفهم، وتأكيدات حذف متناسبة مع خطورة العملية.
21. استيراد/تصدير CSV مع معاينة وربط أعمدة وتقرير عن السجلات المرفوضة.
22. مركز إشعارات داخلي، مع طلب إذن إشعارات Android فقط إذا تم تنفيذ إشعارات فعلية.

## سياسة أذونات Android
- **المتاح الآن:** فتح إعدادات التطبيق الأصلية في Android لمراجعة أذونات النظام.
- **لا يوجد طلب شامل لكل الأذونات:** إضافة أذونات غير لازمة (الموقع، جهات الاتصال، الميكروفون، SMS، سجل المكالمات، خدمات الوصول) تزيد المخاطر وقد تضر الثقة ومراجعة المتجر، ولا تمنح التطبيق حق تجاوز قرار المستخدم.
- **عند إضافة ميزة تتطلب إذنًا:** يُطلب الإذن وقت استخدام الميزة فقط، مع شرح السبب، ومعالجة الرفض، وعدم تعطيل التطبيق كله عند رفض ميزة اختيارية.
- **حدود التحكم:** لا يستطيع التطبيق إجبار Android على منح كل الأذونات؛ المستخدم والنظام يقرران، وبعض الأذونات الخاصة لا تُمنح إلا من إعدادات النظام.

## قيود النسخة الحالية
- البيانات محلية ولا توجد مزامنة تلقائية بين الأجهزة.
- السعة الفعلية للصور تعتمد على الجهاز؛ حد الصورة الواحدة 25 MiB.
- ملف APK الناتج Debug للاختبار والتثبيت اليدوي، وليس إصدار متجر موقّعًا.
- نجاح بناء APK لا يساوي اختبارًا على هاتف فعلي؛ يلزم فحص عملي قبل الاعتماد على البيانات الحقيقية.


## تحديث تجربة الحركة — 2026-10-27
- انتقال دخول خفيف لمحتوى الصفحة عند التنقل، مع تدرج زمني محدود للبطاقات.
- micro-interactions للأزرار والقائمة والبطاقات: استجابة ضغط، رفع بسيط عند التحويم، وتغييرات هادئة للحدود والظلال.
- انتقالات للنماذج والصفوف والصور، ودخول خفيف للتنبيهات والنوافذ عند دعم مكونات الواجهة الحالية.
- احترام إعداد نظام Android/المتصفح `prefers-reduced-motion` لتعطيل الحركات غير الضرورية للمستخدمين الحساسين للحركة.
- تجنب الحركة المستمرة والوميض والتأثيرات الثقيلة؛ الهدف تحسين الإحساس بالجودة دون تشتيت أو إبطاء الهاتف.
